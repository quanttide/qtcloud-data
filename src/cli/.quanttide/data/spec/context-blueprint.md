# context

## 处理步骤

| 步骤名 | 输入 | 输出 | 处理逻辑 | 依赖 |
|--------|------|------|----------|------|
| 步骤名 | 输入(from) | 输出(to) | 处理逻辑(desc) | 依赖(depends) |
| PDF解析与文本提取 | 原始PDF检测报告 | 结构化文本数据 | 解析PDF文件，提取表格文本及元数据（页码、表格位置），生成包含来源机构、报告编号、样品信息、检测指标原始名称、时间点、分组、数值等原始文本记录 | - |
| 指标名称标准化 | 结构化文本数据 | 标准化指标映射后数据 | 根据标准指标映射表，将各机构原始指标名称（如“皮肤水分含量”、“角质层水分含量”）统一映射为标准名称；保留原始名称作为溯源字段 | PDF解析与文本提取 |
| 数值精度与格式清洗 | 标准化指标映射后数据 | 清洗后数值数据 | 保留原始数值精度（不四舍五入），去除单位符号（如“%”），将非数值字段转为标准格式（如日期、时间点），确保可追溯性的元数据字段完整 | 指标名称标准化 |
| 去重与长表组装 | 清洗后数值数据 | 最终标准化长表数据集 | 按（报告编号、样品编号、标准指标名称、检测时间点、分组）去重，保留完整记录，组合成每行一次观测值的长表格式，包含均值、标准差、变化率、P值等字段，并追加溯源字段（报告文件名称、页码、表格位置） | 数值精度与格式清洗 |
| 异常识别与复核清单输出 | 清洗后数值数据及最终数据集 | 异常问题清单及标注PDF | 检测数值异常（如超出合理范围、缺失关键指标），生成问题清单文件，同时在原PDF对应位置标注以便人工复核 | 数值精度与格式清洗 |
