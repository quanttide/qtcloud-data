# <化妆品功效检测报告数据标准化项目>

## 1. 业务背景

-   **客户是谁，做什么业务**：贵司（客户）是一家涉及化妆品功效评估的公司或机构，需要处理来自多家第三方检测机构（如SGS、华测、谱尼等）的化妆品功效检测报告。
-   **当前面临什么问题**：目前，贵司手头有大量（几十份）PDF格式的检测报告，但这些报告的格式、布局和术语命名均不统一。这导致无法直接对这些宝贵的数据进行高效的整合、查询、分析和后续的业务应用。人工翻阅和录入效率低且易出错。

## 2. 数据来源

-   **客户能提供什么数据（格式、大致规模、更新频率）**：
    -   **数据格式**：PDF格式的文件（检测报告）。
    -   **数据规模**：初期预计有几十份报告，具体数量待确认。报告来自SGS、华测、谱尼等多家机构。
    -   **数据更新频率**：目前从聊天记录中看是**一次性数据处理**。后续如需常态化处理，请告知我们报告的产出频率（如每周/每月一批）。
-   **是否有样例数据**：暂时假定有。我们需要您提供1-2份典型的不同机构报告PDF作为样例，以便我们验证数据提取方案。

## 3. 期望产出

-   **客户希望最终拿到什么（报表？数据集？API？）**：**标准化数据集**。即一份可直接用于分析的结构化数据表格。
-   **对产出格式有什么偏好**：
    -   **核心产出**：一份**长表格式**的数据集。每行代表“某份报告、某样品、某检测指标、某个时间点、某个组别”的一次具体观测值。
    -   **辅助产出**：一份**标准指标映射表**。用于明确原始报告中不同机构对同一指标的不同叫法（如“皮肤水分含量”、“角质层水分含量”、“皮肤含水量”）与统一标准名称的对应关系。
    -   **具体字段**：每条数据记录需包含但不限于以下字段：
        -   报告来源机构
        -   报告编号
        -   样品编号/名称
        -   标准指标名称（映射后）
        -   检测时间点（如：0天、14天、28天）
        -   数据分组（如：实验组、对照组）
        -   均值、标准差、变化率、P值（如有）

## 4. 约束与要求

-   **时间要求**：请您提供希望拿到初版成果的预估时间，以便我们制定项目排期。
-   **安全/合规要求**：
    -   检测报告可能包含商业敏感信息，我们承诺所有数据仅在项目范围内使用，不会外泄。
    -   请明确是否有其他数据脱敏或合规要求。
-   **其他特殊要求**：
    -   **数据精度**：必须完整保留原始数值精度，不能进行四舍五入或截断。例如，30.37%必须准确记录为30.37%。
    -   **可追溯性**：每个提取出的数值，必须能够追溯到它来自哪份报告的哪一页、哪一个表格的哪一个单元格。这要求在产出数据集中增加“报告文件名称”、“页码”、“表格位置”等溯源字段。
    -   **异常复核**：提供一个方便的机制（如原始报告PDF标注、或单独的问题清单），当数值看起来有异常时，业务人员能够迅速打开对应报告进行人工复核。

## 5. 待确认事项

为了更准确地评估工作量和启动项目，我们需要与您确认以下几点：

1.  **总数据量**：具体涉及的PDF报告总数量，以及后续是否会持续有新报告加入？
2.  **样例数据**：请尽快提供至少1-2份不同机构（如SGS、华测）的完整报告样例，以便我们进行特征分析。
3.  **标准指标清单**：您期望最终统一映射的“标准指标名”清单是什么？（例如：皮肤水分、TEWL、紧致度、弹性等）。
4.  **关键字段优先级**：列表中“均值、标准差、变化率、P值”等字段，是否全部都需要提取？还是部分优先？
5.  **更新频率**：本次项目是“一次性”处理历史数据，还是需要搭建一个“可定期接收并处理新报告”的方案？
6.  **输出文件格式**：最终数据集是希望以Excel、CSV，还是数据库（如MySQL、SQL Server）的形式交付？
